# BoolNet file format and conventions

**Status: draft v1.** Written from the Julia prototype. Anything here can change
if we agree on something better, but both implementations (Julia and Rust) must
follow whatever this file says.

## 1. What a network is

A synchronous Boolean network with `N` genes. Every gene is either 0 or 1, and
all genes update at the same time:

```pseudocode
state(t+1)[i] = tables[i][ position of (values of inputs[i] in state(t)) ]
```

Each gene `i` has:

- `inputs[i]`: the list of genes it reads (`K_i` of them; may be empty, which
  makes the gene a constant; may include `i` itself)
- `tables[i]`: its truth table, a list of `2^K_i` bits

## 2. JSON schema

```json
{
  "format": "boolnet",
  "version": 1,
  "n": 3,
  "inputs": [[1, 2], [1, 3], [1, 2]],
  "tables": [[0, 1, 1, 1], [0, 0, 1, 0], [0, 0, 0, 1]]
}
```

| field     | type                  | meaning                                           |
|-----------|-----------------------|---------------------------------------------------|
| `format`  | string                | always `"boolnet"`                                |
| `version` | integer               | `1`; readers must reject versions they don't know |
| `n`       | integer               | number of genes; must equal `len(inputs)`         |
| `inputs`  | list of lists of int  | `inputs[i]` = genes read by gene `i`              |
| `tables`  | list of lists of 0/1  | `tables[i]` = truth table of gene `i`             |

### Validity rules (readers must check all of them)

1. `len(inputs) == len(tables) == n`
2. every entry of `inputs[i]` is a gene number between 1 and `n`
3. `len(tables[i]) == 2^len(inputs[i])`
4. every table entry is `0` or `1`

## 3. Conventions

### Gene numbering

- Genes are numbered **1..N in the file** (gene 1 is "A", gene 2 is "B", ...).
- `inputs[0]` in a 0-based language describes gene 1. Rust readers subtract 1
  from every gene number on loading.

### Truth-table position

For gene `i`, read its inputs **in the order listed** and treat the values as
the digits of a binary number. **The first listed input is the most
significant bit.** The result is the **0-based** position in `tables[i]`.

```psuedocode
pos = 0
for j in inputs[i]:
    pos = 2 * pos + value_of_gene_j
output = tables[i][pos]          # 0-based; Julia uses tables[i][pos + 1]
```

Example: gene 2 above has `inputs = [1, 3]` (reads A and C). With A = 1, C = 0
the position is `1*2 + 0 = 2`, so the output is `tables[2][2] = 1`, which is
"A AND NOT C".

### State encoding (integers)

A state is an integer in `0 .. 2^N - 1`. **Gene 1 is the most significant bit**,
so gene `i` sits at bit `N - i` (bit 0 is the least significant).

Example for `N = 3`: state `6 = 0b110` means A = 1, B = 1, C = 0.
For the network above, state 6 maps to state 7.

## 4. Attractors (for comparing results between implementations)

- An **attractor** is a cycle of states under the update rule (a fixed point is
  a cycle of length 1).
- A cycle is written as a list of states in visiting order. Its **canonical
  form** is rotated so that the **smallest state comes first**.
  Example: the cycle 5 → 7 → 6 → 2 → 0 → 1 → back to 5 is written
  `[0, 1, 5, 7, 6, 2]`.
- The **basin** of an attractor is the number of states (including the
  attractor's own states and all transient states) whose trajectory ends in it.
  Basin sizes of all attractors sum to `2^N`.

## 5. Reference networks and expected answers

| network | N | attractors (canonical) | basin sizes |
| --- | --- | --- | --- |
| K=1 toy: `A'=C, B'=A, C'=NOT B` | 3 | `[0,1,5,7,6,2]`, `[3,4]` | 6, 2 |
| K=2 toy: `A'=A OR B, B'=A AND NOT C, C'=A AND B` | 3 | `[0]`, `[4,6,7,5]` | 2, 6 |

The K=2 toy network is exactly the JSON example in section 2.

## 6. Proposed, not yet agreed

- A `golden/` folder with saved networks plus the expected attractors and basin
  sizes (in canonical form), generated by the Julia code, to check the Rust
  implementation and the SAT encoding against.
- A later extension where rules can be given as formulas (for example
  `"A' = A or B"`) instead of truth tables. Truth tables stay as the internal
  representation either way.
